# 🐍 SnakeGH

A customized classic Snake arcade game built using Python 3 and Tkinter, featuring sound effects, dynamic screen wrapping, bonus food, background music, and leaderboard tracking.

## ✨ Features

- **Classic Gameplay:** Smooth grid-based movement with progressive difficulty.
- **No-Walls Mode:** Pass through screen edges and reappear on the opposite side.
- **Golden Jollof Bonus Food:** Timed bonus food worth +3 points.
- **Top 5 Leaderboard:** Automatically saves the highest scores in `snake_highscore.txt`.
- **Game Audio:** Background music and sound effects powered by Pygame.

## 🎮 Controls

| Key | Action |
|---|---|
| Arrow Keys / WASD | Move Snake |
| Spacebar | Start / Restart |
| P | Pause / Resume |
| N | Toggle No-Walls Mode |

## ⚙️ Requirements

- Python 3.x
- Pygame

## 🚀 Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/DrPanks/SnakeGHgame.git
```

**2. Enter the project folder**

```bash
cd SnakeGHgame
```

**3. Install Pygame**

```bash
pip install pygame
```

**4. Run the game**

```bash
python snakegh.py
```
